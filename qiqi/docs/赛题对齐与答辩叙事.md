# 赛题对齐与答辩叙事（银行 AI 智能体 · 理财操作场景深度覆盖）

> 2026-10-10 勘误：README 原写赛题"个人智能理财 Agent"，已更正为"银行 AI 智能体（理财操作场景深度覆盖）"。本文档是答辩 PPT 第一页与作品简介的统一口径来源。

## 一、选题逻辑：为什么只做「理财操作」一个场景

赛题六个场景（转账 / 账单 / 理财 / 卡片 / 订阅 / 跨场景联动）中，理财操作与其他场景有**本质区别**：

1. **唯一"资产动账 + 红色强验证"的场景**。赛题权限分级表明确：理财产品申购须"人脸识别、短信验证码或 U 盾等多因子认证"——理财是六场景中安全要求的天花板，而安全占评分 30%。
2. **大模型最危险的失效模式全部集中在理财**：幻觉价格（凭空报成交价）、超卖持仓、买入禁止行业、资金不足——每一条都对应真实资金损失。这些正是我们的确定性风控闸门逐项拦截的对象。
3. **深度 > 广度**。赛题核心要求是"在严格的安全框架内完成银行业务操作"。一条每个环节都可审计、每次动账都过确定性闸门的完整可信闭环，比六个场景的浅覆盖更能证明这一点。

**一句话定位（PPT 第一页可用）**：
> 《持仓哨兵》——银行 AI 智能体，选择把「理财操作」这一个场景做到可信闭环。理由是：理财是六个场景中唯一要求"资产动账 + 红色强验证"的场景，安全纵深在这里不是加分项，而是生存项。

## 三、核心差异化叙事（创新点怎么讲）

按"无先例 → 有官方背书 → 有实证"的顺序，主打三个点：

1. **记忆投毒防御（主打）**：写入侧信任分级（trust 只升不降）+ USER/MENTAL_MODEL 层禁止直写 + 读取侧 spotlighting 隔离。背书：MITRE ATLAS 正式收录 `AML.T0080 AI Agent Context Poisoning`；OWASP LLM01 缓解第 6 条"隔离并标注外部内容"即我们的实现。全网核验：**没有开源项目做过这套组合**，且全球尚无金融 agent 记忆投毒的 CVE 与公开损失案例——我们是这个威胁模型的实证落地。
2. **确定性风控闸门（fail-closed）**："LLM proposes, Python disposes"——LLM 提出建议，7 项确定性检查放行，任何检查抛异常一律保守拦截；叠加三级权限与强验证。对应赛题"严格的安全框架"的机制化答案。
3. **五层演化记忆的工程洞察**：跨天证据才涨置信度（同日反复体检不虚高）、去重增强只升不降、reflect 按"证据天数"而非"条数"提炼规则——这些是解决真实工程问题时的原创设计，答辩时各用一句话讲"为什么这么做"。

## 四、200 字作品简介（报名系统提交用）

> 《持仓哨兵》——银行 AI 智能体理财场景的深度实践：用户以自然语言或卡片发起意图，Agent 自主完成意图识别、持仓诊断、风险检查与情景推演，输出可解释的调仓建议。系统以「LLM 决策 + 确定性风控闸门」双引擎运行，绿黄红三级权限、多因子强验证，每笔动账前严格准入；独创五层演化记忆与记忆写入门卫（信任分级 + 注入拦截），越用越懂用户且无法被投毒。全程纸交易仿真，决策链路可审计回放。

（约 190 字，含创作理念与所用 AI 技术；如需更短可删"情景推演"与"纸交易仿真"两句。）

## 六、评委预期追问与回答口径（Q&A 预演）

- **Q1：「其他五个场景为什么不做？」** → 见第一部分：理财是唯一"资产动账+红色强验证"的场景，安全权重 30%，我们把一个场景做成可信闭环。广度的代价是安全承诺变薄，这不是我们选择的路线。
- **Q2：「自然语言入口在哪？」** → 诚实回答：当前 Demo 为卡片+流程化发起，NL 层在路线图首位，`question` 参数入口已预留；产品理念中"只追问必要项、不猜测风险偏好"的对话设计已在 PRD 定义。
- **Q3：「和 OpenClaw / Revolut AIR 比，你的创新在哪？」** → 我们的差异化在安全纵深而非交互广度：确定性闸门 + 记忆投毒防御 + 五层记忆，对标的是"银行内控要求"而非"更流畅的聊天"。
- **Q4：「记忆到底改变了什么决策？」** → 现状：recall 进入决策上下文 + reflect 生成心智模型提示；机制化联动（心智模型 → 审批阈值）在路线图。诚实回答比过度包装安全。
- **Q5：「异常熔断和沙箱呢？」** → 熔断为 P1（信号源已就绪）；沙箱口径：不生成执行代码 + JSON schema 强约束 + 纸交易隔离。
- **Q6：「安全怎么测的？」** → 15 个烟测用例（正常/注入/层策略/截断/信任分级/spotlighting 全路径）+ 本地化注入测试集（进行中，给拦截率与误伤率数字）+ 演示数据一致性三处修复记录。
