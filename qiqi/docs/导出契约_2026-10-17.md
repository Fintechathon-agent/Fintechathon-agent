# 导出契约：一份 artifact，五个渲染器（2026-10-17）

> 10-17 会议口径：「agent 生成、整理的数据，怎么以 PDF、PPT、Word、Excel、图形在 UI 里更美观优雅地呈现，接口要和小果、林粹对一套，不要各做各的。」
> 本文是那一套接口的说明。代码在 `contracts/report.py`，校验在 `tests/test_report_contract.py`（17 项，全过）。

## 一句话结构

```
agent 产出 ReportArtifact ──► 渲染器（pdf / pptx / docx / xlsx / png）──► 文件
                          └──► UI 直接渲染同一份（html）──► 屏幕
```

**agent 只管内容，不管排版**；渲染器只管把同一份结构画成各自格式；UI 和导出文件看到的是同一份东西，不会出现「屏幕上和导出的不一样」。

## 三种角色各自要做什么

| 角色 | 需要做的事 | 不需要做的事 |
|---|---|---|
| agent / 数据侧（林粹、我们） | 按块类型产出结构化内容，填 `provenance` 和 `disclaimer`，调 `validate_artifact()` 保证过 | 不拼 HTML、不算字号、不决定分页 |
| 渲染侧（谁接谁写） | 消费 artifact，按块类型分派，用各格式原生能力重绘（Excel 原生图表、PPT 原生图表、PDF 矢量） | 不改数据、不补默认值、不静默丢块 |
| UI 侧（小果） | `GET` 到 artifact JSON 后直接渲染；`export_formats` 决定「导出」菜单显示哪几项 | 不再单独维护一套导出用的数据结构 |

## 块类型（封闭集合，8 种）

| kind | 用途 | 关键字段 |
|---|---|---|
| `heading` | 章节标题 | `text`、`level`(1~4) |
| `text` | 一段正文（不解析 Markdown） | `text` |
| `bullets` | 无序要点 | `items[]` |
| `metrics` | 关键指标卡 | `metrics[]`：`label / value / unit / delta / tone` |
| `table` | 表格 | `columns[]`、`rows[][]`、`column_formats[]`、`align[]`、`highlight_rows[]`、`total_row` |
| `chart` | 图表（只传数据，不传图片） | `chart_type`、`x_labels[]`、`series[]`、`unit`、`stacked` |
| `callout` | 提示框（风控结论、Mock 标注、口径说明） | `tone`(info/warn/risk/success)、`text` |
| `image` | 本地图片（禁止外链） | `path`、`alt`、`caption` |

**列格式是这套契约里最容易被忽略、但最影响观感的一项**：`text / int / money / percent / date / delta`。金额、百分比、日期一律交给渲染器按格式画，不要各端自己 `f"{x:.2f}"`——Excel 单元格格式、Word 表格、PPT 表格、PDF 绘制都读这一列。

## 三条硬规则（校验会拦）

1. **来源必填**：`artifact.provenance` 或每个 `section.provenance` 至少有一个，`source` ∈ `demo / live / user_import / model / memory`，`as_of` 必须是 ISO 时间。
2. **demo 必带免责声明**：`meta.mode="demo"` 时 `meta.disclaimer` 不能空；`mode="live"` 但来源里含 `demo` 会被判为口径不一致。
3. **结构与数据对齐**：`table` 每行长度必须等于 `columns`；`chart` 每条 series 的点数必须等于 `x_labels`；`pie/donut` 只允许一条 series；`image.path` 不允许出现 `://`。

## 章节如何映射到各格式

`ReportSection.page_break_before` 是跨格式分页的唯一开关：

| 格式 | `page_break_before=true` 的含义 |
|---|---|
| PDF / Word | 另起一页 |
| PPT | 另起一张幻灯片 |
| Excel | 另起一个工作表（表名取 section.title） |
| PNG | 另起一张图 |

## 导出接口

```python
from contracts.report import ExportRequest, ExportResult, assert_valid, suggest_filename

assert_valid(artifact)                                    # 出文件前必过
request = ExportRequest(artifact_id=artifact.artifact_id, format="xlsx")
filename = request.filename or suggest_filename(artifact, request.format)
# 渲染器返回 ExportResult(status="done"|"failed"|"unsupported", path=..., renderer=...)
```

`unsupported` 是显式状态：某个渲染器表达不了某个块时，必须报 `unsupported` 并说明是哪一块，不允许静默跳过——这样「五个格式对一套」才不会被悄悄破坏。
