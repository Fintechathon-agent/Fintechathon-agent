# Weekly Market Brief · 周报模板（2026-10-07 登记）

> 蓝本：群内国庆周版（10/01–10/07）。与日版同一套骨架、改周度口径；发布前过「核验五问 + 自检四问」。

```
【Weekly Market Brief｜××周 MM/DD–MM/DD 全局复盘周报】

1. 市场行情（周累计口径）
- 核心资产 4-6 个，一行一个：周累计涨跌 + 关键点位 + 一句状态。

2. 异常波动（含驱动）
- 本周异常资产：幅度 + 驱动（地缘/天气/政策/资金）；推断标「（推断）」。

3. 重要财报（本周海外财报 & 业绩指引汇总）
- 逐条：公司 → 指引/数字 → 与市场预期的关系；末尾一行「小结」。

4. 重大新闻
- ①②③… 每条带时间/来源；未获一手确认的标「待确认」。

5. 一句解释
- 1-2 句把本周主要矛盾串起来（含多空对冲关系）。

6. Agent 映射
- 各信息 → Data / Research / Risk / Memory；
- 录入范式：一句话写清这组信息未来怎么被 Agent 使用（例：长假海外单边行情 → 节后跳空定价）。

7. 今日问题（周报语境＝本周问题）
- 给 A/B/C 选项 + 引导理由，群里回复。

---
*数据留档：`brief/out/…`｜核验记录：…*
```

## 发布前检查（硬性）

1. 每个数字能在**当周存档**里找到（行情＝新浪/东财双源；美债＝财政部官方；公司数据＝公告原文）。
2. 周累计类数字无法回溯到逐日数据时 → 补采或标注口径，不硬写。
3. 与同期日报数字**不得互相矛盾**（飞书文档内会被对照阅读）。
