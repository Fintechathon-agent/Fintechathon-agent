## 复现

准备上述基线的干净个人预览副本，先安装/提供 Playwright 和 Chrome。以下命令均在本目录执行；将 `<preview-root>` 换成副本绝对路径。

用途：应用本轮UI转换。脚本拒绝对已转换页面重复运行。

```powershell
node refine-preview.cjs <preview-root>
```

用途：更新发布清单并生成覆盖包。此步骤不上传任何内容。

```powershell
node package-release.cjs <preview-root>
```

用途：在本地静态服务上复验界面，不发出付费模型请求。默认服务地址为 `http://127.0.0.1:4187`；可通过 `PREVIEW_URL` 指定。

```powershell
node browser-check.cjs <preview-root>
```

发布通过个人预览 `preview` 分支触发GitHub Pages；团队工作分支用于审查和留档，不自行合并。线上发布状态、提交编号与验收结果记录于 `DELIVERY.md`。
