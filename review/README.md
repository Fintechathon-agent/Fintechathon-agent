# 本地检查版本

从完整首页进入，再检查个人投资和店主经营两条流程。报告包含截图、提交记录、验证边界与五项重点验收。

先在 `chenchen` 目录运行 `npm run build:static` 生成静态演示，再从仓库根目录运行 `node review/serve.cjs` 启动仅本机可访问的检查服务。

- 验收报告：<http://127.0.0.1:4179/>
- 完整静态演示：<http://127.0.0.1:4179/demo/>
- 投资页：<http://127.0.0.1:4179/demo/investment.html>
- 店主页：<http://127.0.0.1:4179/demo/merchant.html>

服务只监听 `127.0.0.1`，不会公开到互联网。端口占用时可通过 `REVIEW_PORT` 环境变量指定其他端口。重启电脑后需重新运行服务；修改网页后需重新构建静态演示。

`overnight-2026-10-07.html` 本身也可以直接用浏览器打开阅读，截图使用相对路径。静态演示包含模块脚本，需通过上述 HTTP 地址打开，不能直接双击其 HTML 文件。

演示沿用项目原来的计算与合成数据；静态版本会话仅在当前页面内存，刷新会重置。没有接入真实账户或交易。
