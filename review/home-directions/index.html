B / 决策步骤

C / 单一入口

一个组合健康检查入口。收益 / 风险天平收进卡内；不表示两者可以相抵，也不提供收益承诺。

三种均下线原型中的店主入口。正式首页、产品导航、工作台与公网演示未改；选定后才统一修改。此处 A / B / C 是布局方向，与投资候选方案 A / B / C 无关。按钮仅打开入口说明，不请求 API、不提交确认、不执行交易。容器交互用于评审布局，正式硬币四来回动画的迁移需在选定后回归。
