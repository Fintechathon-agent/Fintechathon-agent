# 风控工作台：产品与视觉边界

本页面供队内和评委用虚构数据验证第四板块。实现 R01—R10、ALLOW/REVIEW/BLOCK/ERROR、逐项风险接受、整计划确认、失败暂停、幂等和审计。普通用户必须先确认约束，再运行检查与确认完整计划；通过检查本身不能执行。

安全演示允许在账单备注或新闻文字中输入攻击，展示数据与权限分离、Risk 原因、网关阻断及实际审计。当前 Core 为确定性工作流，额外越权请求由演示器构造；不宣称大模型攻击识别或正式认证通过。

## 继承团队界面

- THESIS：从输入、原因到确认与结果，让每一步都有可查看的依据。
- OWN-WORLD：继承 `chenchen/versions/style.css` 的浅纸色、深绿色、简洁中文金融工具风格。没有新品牌、摄影或材质复刻要求。
- STORY：主流程提示 → 攻防演示 → 约束输入 → 风险检查 → 确认 → 执行 → 审计。
- FIRST VIEWPORT：可识别产品、虚构数据范围和攻击输入；运行后在同一区域展开三个阻断层及零工具调用证据。
- FORM：桌面双列审核工作台；手机单列。使用原生表单、明确禁用状态和文本原因，颜色不是唯一状态信号。

本轮为既有视觉系统的扩展；共享设计文件和团队原页面不在本轮修改范围。
