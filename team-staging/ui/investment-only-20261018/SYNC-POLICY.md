# 本模块双仓库同步规则

2026-10-18 起，用户确认的发布目标为：

1. lixjanus526-art/finance-lab-ui-preview：个人成果与可访问 UI 预览；尊重既有分支与工作台，独立候选优先放子目录。
2. Fintechathon-agent/Fintechathon-agent 的 team-staging/：开发代码、必要资源、测试结果和交付说明；优先使用功能分支及 PR。

不更新 team-release，不直接合并团队 main，不强制推送，不覆盖他人代码，不把完整静态构建包放在团队仓库根目录，不上传密钥或环境配置。旧个人仓库 finance-lab-demo 只有用户单独要求时才更新。

每次交付均核对两个远端提交、个人预览实际页面和团队文件路径，并报告未完成事项。若目标不可访问或不可写，明确标为未同步。
