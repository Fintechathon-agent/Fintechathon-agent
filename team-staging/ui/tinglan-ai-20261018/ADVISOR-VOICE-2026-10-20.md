# 分析口吻整改：从"免责声明"改成"顾问说人话"（2026-10-20）

## 这份文档解决什么问题

10-20 上午用户实测分享站 `xinlan-qwen38-share.lixjanus526.workers.dev`，在"听澜 AI 助手"里填了
150 万元、25 天、中等风险、最多亏 7%、目标"短期冲高"，模型回来的第一段是：

> 用户自述风险偏好为中等，计划投入150万元人民币，期限极短（25天），最大可承受回撤7%，目标为短期冲高。
> 鉴于缺乏实时行情、账户核验及详细财务状况（如备用金、负债等），无法提供具体投资建议或适当性结论。

用户的判断是：**"这种分析我完全不会看，用户也听不懂。"** 这个判断是对的。问题不在模型能力，
在提示词和界面把模型逼成了合规文书。

## 根因（全部已核实，有代码位置）

| 层 | 问题 | 位置 |
| --- | --- | --- |
| 提示词 | `requested_action` 明确要求写"中文投资偏好**教育分析**"，并写了"**不编造比例或个性化适当性结论**"，模型只能端免责声明；还硬性要求四个带标题的段落，逼成公文 | `gateway.mjs` 原第 77 行 |
| 前端结构 | 结果区写死"用户风险偏好总结 / 资金配置、期限、资产类别与主要风险 / 输入依据 / 待补充信息"，标题本身就是第三人称转述 | `frontend/panel.html` |
| 前端呈现 | `reason` 整段塞进一个 `<p>`，模型写四段也挤成一块；还显示"Live AI 模型返回"这类内部术语 | `frontend/widget.mjs` |
| 质量闸门 | 只校验"四个标题是否都在"，等于奖励写标题的套话、惩罚真的给建议 | `gateway.mjs` + `frontend/client.mjs` |
| 本仓库主链路 | `COMMON_RULES` 只要求"语言精炼"，没有要求给数字、没有禁止第三人称和套话 | `agent/tools/financial_llm.py` |

## 改了什么

### 1. 提示词（`gateway.mjs` 的 `ADVISOR_INSTRUCTIONS`）

- 角色从"审核员"改成"这位用户自己的投资顾问"，**用第二人称"你"**。
- `summary` 必须是一句话结论，**必须含具体配置**（金额或比例 + 产品类别）。
- `action_reason` 写 3–4 段自然段：具体怎么放 → 为什么这么放（**用用户给的数字算给他看**）→ 代价和收益量级 → 什么情况下要改，**必须出现具体金额或比例**。
- 目标和约束矛盾时**直接说破**（25 天想冲高、回撤 7% 想满仓权益）。
- **禁止**"适当性 / 教育性分析 / 仅供参考 / 不构成投资建议"这类套话；专业词第一次出现要用大白话解释。
- 信息不全时**先按合理假设给方案**，`missing_information` 最多 2 条，只列真正会改变结论的问题，不能拿缺资料当拒绝给建议的理由。

### 2. 质量闸门（`advisorQuality` / `readResult`）

不再检查"四个标题"，改成检查**像不像顾问**：`summary` ≥12 字、`reason` ≥100 字、至少 2 处金额或比例、必须用"你"、套话命中即拒、缺失项 ≤3 条。服务端和浏览器端各校验一次。
不合格返回 `MODEL_INVALID_RESPONSE`，失败文案也改成人话（"这次没有给出可执行的分析，请补充资金用途后重试"），不再展示旧结果或降级成固定答案。

### 3. 界面（`panel.html` / `widget.mjs` / `tinglan.css`）

结果区标题改成 **结论 / 具体怎么放 / 我依据的是什么 / 还需要你确认**；`reason` 按换行拆成多段 `<p>` 渲染；去掉"Live AI 模型返回"，只保留模型名/耗时/token；底部说明改成"模型看不到你的账户和实时行情，它不替你下单"。

### 4. 本仓库主链路（Python 侧）

- `agent/tools/financial_llm.py`：`COMMON_RULES` 增加"用你、必须带数字、缺数据先给方案、禁套话、术语要解释"；Portfolio / Decision 两个输出结构的字段说明改成必须带数字。
- 新增 `advisor_voice_issues()`：对模型回答做口吻体检（太短 / 没数字 / 第三人称 / 有套话）。
- `DecisionMaker` 记录 `last_voice_issues`，经 `AgentResponse.advisor_voice_issues` 透传到 `/api/review`；`web/static/app.js` 命中时在结果上显示"这次分析没讲清楚：…"，**不拦建议、不假装正常**。
- `agent/core/intent.py`：`missing` 键名（标的 / 适当性复核）在回给用户时翻译成"具体买哪只、卖哪只""这笔买入是否在你的风险承受范围内"；程序内部判断仍用原键名，测试不变。
