# 长文本生活资金与风险模块

将一段包含房租、学费、工资和投资的中文描述整理成可核对事项，在确认金额、日期和资金事实后，用现有 Risk 策略计算资金冲突。页面支持修改、重新测算、收支时间线和 JSON 导出。

## 启动

**工作台集成版**：已接入现有 `/risk` 任务、确认、沙箱记账和审计，并接通团队在线模型。Windows 双击 [start-workbench.cmd](start-workbench.cmd)，或按 [INTEGRATION.md](INTEGRATION.md) 启动。入口为 <http://127.0.0.1:8780/risk/long-text>。线上原站更新仍需站点编辑权限。

以下命令保留独立测算模式：

需要 Node.js 22 或以上版本，以及完整仓库（会引用 `chenchen` 中的模块）。无需安装第三方依赖。

在仓库根目录执行：

```sh
node team-staging/risk/long-text/server.cjs
```

打开 <http://127.0.0.1:4182/>。Windows 也可以双击本目录的 `start.cmd`。端口可通过 `LONG_TEXT_PORT` 修改。

点击一个虚构案例，选择分析日和 30 / 90 / 180 / 365 天区间，拆分并核对。逐项勾选后，填写实际采用的现金、独立保底、已有占用和费用；没有占用或费用时明确填 0。点击“确认本版本并测算”。修改原文或金额后，旧结果失效，须重新核对。

## 支持的能力

- 最多 20,000 个 UTF-16 字符；继承 Core 的 80 个基础语句上限，细分后最多 100 个事项。保留每条原文的起止位置。
- 中文、阿拉伯数字、全角数字、万/千以及 k/w 金额，支持数字与单位间的空格；列表编号不作为金额。内部统一使用人民币整数分。
- 相对日期、年月日、下周几、月底和月/周/日周期。月底 31 日跨短月后恢复原始日期。
- 区分现金、保底、生活支出、收入、投资和现有资产；识别已支付、取消、条件、他人事项、否定、修改和完全重复的描述。
- 金额范围、外币、日期不明、混合资金用途等情况保留待核对，不自动猜测。复杂混合句需回到原文分别写明。
- 留学、机票、生活费、旅游分别归类；标题、地点和提问保留为补充背景，默认不作为独立收支。背景归类仍可修改和核对。
- 拆分后立即显示未确认的预算概览：已知支出合计、现金扣除这些支出后的余额区间、缺失预算。范围如“4 到 6 万”保留上下限，可明确选择上限预留；“余款／all in”记录为投资意向，不自动分配或重复计入余款。
- 投资与生活支出冲突、保底不足、未来收入和工资延迟压力情景；结论有来源、金额和原因。
- 会话隔离、30 分钟草稿有效期、版本与内容绑定、修改使确认失效、失败请求不部分修改数据。
- 本地风险 JSON、审计记录、既有 `model-review.v1` 请求导出；可配置的在线只读复核入口。

## 计算口径

本入口只接受 `FIXTURE` / `SYNTHETIC_REPLAY`。所有案例都是虚构数据，不连接账户、不修改 Memory、不产生付款或交易。

当前可用额度 = 现金 − 已有占用 − 区间生活支出预留 − 独立现金保底，下限为 0。安排后剩余额度进一步扣除投资计划合计与费用，可以为负。未来工资只进入时间线，不增加当前投资额度。已付款不再次扣除。保底、预留、已有占用须互不重复；页面中的“资金事实”是最终统一计算口径，事项中的现金/保底金额只是原文线索。

核对前的预算概览是部分预算，不等于上述可投资额度：尚未填写的旅游预算、投资、独立保底、已有占用及费用不会被猜测为零。一次性总额可先汇总，周期支出须有起始日才能展开；一年费用不自动按月重复。进入逐日测算或在线复核前仍须补齐金额、日期，确认各项费用没有重叠。

投资合计保守地按分析日一次性占用，即使原文给出未来投资日期。周期投资需要改成区间总额或逐笔列出。区间外、逾期或未知日期不会被静默忽略。每类收支最多展开 200 笔；超过限制需缩短区间。结果中的 `ALLOW` 仅说明该合成场景没有触发硬冲突，`execution_allowed` 始终为 `false`。

风险算法来自 `codex/daily-risk-workbench-v1` 的固定提交；来源与哈希见 [vendor/provenance.json](vendor/provenance.json)。未改动风控规则；仅调整拷贝文件中的本地配置引用路径。

## 可选模型复核

默认不联网。只有服务端设置 `LONG_TEXT_MODEL_REVIEW=1` 后才显示在线按钮；用户点击后才提交当前原文及已确认的结构化上下文。配置复用 `chenchen/integrations/model-review.js` 及其现有供应商说明，不新增凭据文件。供应商可能需要独立预算与认证配置；未满足时明确失败。

模型复核不代替已核对的规则结果，不能授予 Risk 审批或执行权。超过既有 12,000 字符上下文上限时仍可使用本地结果，但不提交模型。不要将凭据写入前端或提交到 Git。

此版本不是公开部署服务：仅监听回环地址，进程重启清空草稿。正式接入需复用工作台身份、账本证据、Risk 服务和审计持久化；不能把这里的合成数据确认直接当成正式资金授权。
