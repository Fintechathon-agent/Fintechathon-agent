# 投资理财页面 UI 接回说明 · 2026-10-20

## 为什么要改

前一轮为了让报告更容易看懂，页面只留下了结论、数字和折叠详情。功能没有丢，但页面看起来像一张长报告，团队之前设计的“先看总览、再进入不同区域”的感觉不明显。

## 这次加回来的内容

- **总览横幅**：先显示一句话结论，例如“这段演示数据里，组合下跌 2.79%”，并明确当前只是在等风控复核。
- **三个重点卡片**：组合表现、现金缓冲、第一关注点。用户先看数字，再点“小提示”理解原因。
- **分区跳转**：总览、先做什么、看方案、看集中度、运行记录可以直接跳到对应位置。
- **手机布局**：卡片在窄屏自动上下排列；桌面保留三列，重点数字继续突出。

## 数据和安全边界

这些 UI 只读取已有 `investment-agent.v1` 健康检查结果，没有新增计算，没有修改 Quant、Memory、Risk 或审批规则。方案仍然只是历史样例比较；任务仍停在 `HANDOFF_REQUIRED`，没有交易执行入口。

## 实测结果

本地浏览器用固定演示组合运行一次健康检查，实际看到：

- 总览横幅显示组合下跌 `2.79%`；
- 重点卡片显示现金比例 `32.18%`，第一关注点为先核对房租、学费和备用金；
- “小提示”和分区导航可以点击，详细内容默认收起；
- 页面仍显示“已完成分析 · 等待风控复核”，没有显示成交或执行成功；
- 原有易读报告、三方案比较、集中度和审计记录入口仍可用。
