## 已完成的核心接口工作

1. **模型配置隔离。** 选择 DeepSeek 时只读取明确设置的 MODEL_API_KEY、MODEL_NAME 和可选 MODEL_API_URL，不再误用 OPENAI_* 配置或默认 OpenAI 模型名。配置不完整时在调用前报错，并留下失败记录；健康检查也会显示未配置。非默认协议必须显式指定对应地址。
2. **落实已有响应格式。** 把既有六个字段、允许的取值与 JSON 格式示例送给模型。缺字段、错误风险值、额外字段或错误数组类型不再被悄悄修补成正常提议。使用现有错误码，不增加公共字段或更改 Risk 状态。
3. **旧任务重试兼容。** 只对早期缺少 scenario/output_formats、且当前仍使用默认值的相同请求兼容旧摘要。金额、正文、场景或输出要求变化仍返回冲突，避免重试变成新任务。测试包含持久化记录重新加载场景。
4. **一句话整理成待确认清单。** 原句、来源位置、金额原写法、日期线索和缺失问题都可查询；生活开支与其他用钱计划同时出现时提示进一步核实。当前采用规则生成候选，所有条目待确认，不写 Memory、不自动提交任务，不做可信余额计算或正式风险判断。
