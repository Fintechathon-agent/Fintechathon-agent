# 投资助手 1000 例可复跑测试

用 46 个模板生成 1000 个参数化案例，固定种子 20261019。检查已有软件行为，**不是训练模型，也不是 1000 个独立真实用户场景**。全部是虚构数据，不含聊天、截图原件、用户账户或密钥。

从 `chenchen/` 执行，需要 Node.js 22+，不需要安装依赖、不读取环境密钥：

```powershell
node experiments/investment-benchmark-v1/run.mjs --output-dir "$env:TEMP/investment-benchmark-new-run"
```

输出目录必须是新目录，脚本拒绝覆盖旧结果。脚本在测试期间阻止全局 fetch；模型、Risk 与审批由明确的本地替身提供，真实/付费请求为零。任一断言失败或尝试外部请求时退出码非零；不会删除失败用例或改成跳过。

| 分组 | 数量 | 验证点 |
| --- | ---: | --- |
| 小额金额 | 150 | 小数点、角分、元角分原文完整性与位置 |
| 生活请求语义 | 100 | 否定、取消、申请取消、假设、他人信息、金额更正 |
| 账户汇总 | 150 | 盈亏显示、收益率显示、零基数、数据不足、不一致 |
| 持仓输入 | 100 | 既有演示证券、未知证券、重复持仓、手数与日期 |
| 持仓分析主链路 | 50 | 完整链路与偏好缺失；调用原工具，不重新实现 Quant |
| 生活资金冲突 | 100 | 用途预留后可用额度，以及差一分钱的冲突 |
| 多任务抢占 | 50 | 两个已审批的合成任务不可重复使用同一笔预算 |
| Risk 与审批 | 100 | 通过、拒绝、要求补资料、缺正式网关 |
| 异常与重试 | 100 | 模型失败、真实计时器超时、重复请求、改参数、批准过期 |
| 报价和订阅 | 100 | 三份人工转录报价、小额优惠、未知条件、取消申请仍预留扣费 |

`cases.jsonl` 是输入与预期；`results.jsonl` 是逐例结果；`workflow-evidence.jsonl` 保存模型替身请求响应、接口操作与完整最终任务审计。摘要在 `report.json` 与 `测试报告.txt`。预期是按业务约束预先定义的断言，不是抄被测输出作为答案。相同种子的数据指纹相同；任务编号、审计时间与计时结果会变化。

模型故障路径刻意使用既有失败响应结构 `model.status / model.response`；不要求它伪造成功结构中的 `model_response.call_succeeded`。超时用 15ms 的测试配置，不是生产 45 秒的真实公网延迟。资金并发为同进程竞态测试；内存对象重建不是跨进程恢复或云端压测。

参考 [本轮结果与修复说明](../../docs/investment-benchmark-1000-2026-10-19.md)。旧 v0 识别器未修改；v1 修复可通过 Git 历史回溯。不能用此测试的通过率宣称真实大模型理解准确率、收益预测能力、真实账户可信或公测准备完成。
