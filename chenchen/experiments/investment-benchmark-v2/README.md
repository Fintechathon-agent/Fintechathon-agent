# 投资助手追加 2000 例验证

本批共 2000 个参数化合成案例，覆盖 10 组、71 个模板。主种子 2026101902，第二半使用 2026101903，区别于上一轮 20261019。复用 v1 执行器，在第二半替换小额、语义和异常的部分模板；新增 25 个模板，不是 2000 种独立业务，也不是模型训练数据。

在 `chenchen/` 中运行（Node.js 22+，无依赖安装、密钥或付费请求）：

```powershell
node experiments/investment-benchmark-v2/run.mjs --output-dir "$env:TEMP/investment-benchmark-2000-new-run"
```

目录必须不存在，拒绝覆盖任何旧结果。输出与 v1 相同：cases.jsonl 保存输入和预期，results.jsonl 保存逐例结果，workflow-evidence.jsonl 保存流程记录，report.json 和测试报告.txt 保存统计及边界。失败或外部请求尝试使进程非零退出；不跳过失败案例。

本轮重点：

- 金额：负数、零值、小于一分的原文、元角分、多个金额，以及“评分/时长的分”与“钱的分”的区别。原文提取不代表接受非法精度或授权金额。
- 语义：双重否定、犹豫、提问、前后矛盾应先澄清；明确计划、已付款、普通否定和假设范围继续检查。
- 审批：新增 100 例，在已完成本地签名 Risk 和审批后，分别改金额、币种、动作参数、资金计划版本、提议指纹（每类 20 例），要求 409、对应错误码、无模拟回执且审计仍可查。
- 原有持仓输入与分析、资金用途预留、多任务竞争、Risk 拒绝/补资料/未接网关、模型异常与超时、幂等、过期、报价订阅继续覆盖。

两个种子只提供参数变化；某些边界输入（零金额、故意非法格式等）会重复，不能以案例总数宣称独立场景数。固定模型与 Risk 替身只验证软件流程；同进程 Worker 路由调用、存储对象重建及资金竞争不等于 Cloudflare 公网调用、真实服务恢复或负载测试。金额和语义仍是有限规则，未验证任意中文理解能力。

追加 4 项回归包含未出现在这 2000 例模板中的措辞，如“得分为八十分”“视频耗时约3分”“没有说不付房租”，并检查澄清提示、原文位置和执行阻断。
