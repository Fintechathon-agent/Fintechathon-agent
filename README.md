# 金融比赛 · Finance Lab

投资理财与店主财务两种场景，保留原有金融计算与核对流程，采用参考 KOSX 的黑橙视觉。独立比赛演示，使用虚构数据。

![投资工作台](chenchen/docs/ui-redesign/investment-desktop.png)

从仓库根目录运行服务（Node.js 22+，无运行依赖）：

```powershell
node chenchen/server.js
```

打开 [投资工作台](http://127.0.0.1:4175/) 或 [店主工作台](http://127.0.0.1:4175/merchant)。
