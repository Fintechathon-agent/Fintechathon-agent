## 需要明确批准的项目

既有提案列出邹昕成（架构/API）、潘心恬（Risk/权限/审计）、陈金宝（会话/任务）为待确认 Owner；请团队确认实际责任人，不推断任一人的批准。

| 审批项 | 待定契约和验收 |
|---|---|
| 身份 | 认证供应方、登录/回调/登出路径、Cookie 范围、过期及撤销；密码不存前端 |
| 身份读取 | GET /api/identity/me：可信主体、工作台、能力；401 未登录、403 未获授权；不接受客户端角色自授 |
| 对象授权 | Personal 仅本人；Analyst 仅分派案件；Supervisor 本组织范围；Admin 默认无金融详情和审批权 |
| 模拟事件入口 | 是否允许新增 POST /api/demo/risk-events；仅模拟环境及获授权主体，绑定请求幂等键、主体与 task_id；不接受客户端风险结论 |
| 事件投影 | Personal 只收可披露原因/下一步/进度，不能先收到内部记录再隐藏；通知更新和已读语义 |
| 内部复核 | 与用户 safety/confirm 完全分离；分析员意见、主管结论、版本冲突 409、幂等重放及分派范围 |
| 同步/审计 | 事务性状态与日志写入，失败不得成功；actor、event、request、前后状态、decision version；查询脱敏、排序和保留期限 |
| 执行门槛 | 复核结束不覆盖 BLOCK、不代理用户确认；重评生成新版本；无回执不显示执行成功 |
| 部署 | 172.27.253.10 的服务用途、协议、端口、基础路径、VPN、认证、只读联调许可、CORS；不猜测 |

最终接口形状及错误体由 Owner 定稿，沿用既有提案的权限矩阵和路由建议。建议所有读写默认拒绝，接口独立校验主体、能力、组织、对象归属；登出/撤权后旧会话不能继续读写；变更使用 CSRF、版本和幂等检查。
