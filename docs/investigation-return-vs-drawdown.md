# 投资结果：区间收益与最大回撤相同的调查

调查日期：2026-10-07。代码基线：`c77807e`。范围仅阅读和复算，未修改公式、演示价格、业务状态或接口。

## 结论

**本例不是两个指标误用了同一个计算，也不是目前可确认的公式 bug。** 三条路径的起始净值 1 是整段最高点，最后一天又是最低点，因此“首尾损失”恰好等于“从历史高点到最低点的损失”。

不能准确地称为“窗口单边下跌”：9 月 18 日和 9 月 22 日都有反弹，只是没有超过起点，且终点仍最低。当前页面并排显示相同值容易让评委误解，这是演示数据代表性和解释方面的问题。

## 代码证据

- [`metricsFromPath`](../chenchen/tools/financial-tools.js) 第 233–254 行：区间收益在第 247 行计算 `最后净值 - 1 - transactionCost`；最大回撤在第 238–242 行循环维护 `peak = max(peak, value)`，再取 `min(maxDrawdown, value / peak - 1)`，第 250 行输出。两者是独立计算。
- 同文件第 497–506 行：费用是实际单向换手率乘演示费率。回测路径第一个点固定为 1，后续点已经扣费，再调用 `metricsFromPath(path)`，没有把费用第二次扣入区间收益。
- [`demo-portfolio.json`](../chenchen/data/demo-portfolio.json) 第 51–66 行：价格窗口为 2026-09-15 至 2026-09-23，仅 7 个观测值，标注为合成历史演示。
- [`investment.js`](../chenchen/versions/investment.js) 在三条路径卡片中分别读取 `c.metrics.cumulative_return` 与 `c.metrics.max_drawdown`，不是用同一个字段填充两列。

|---|---:|---:|---:|

| 09-16 | 0.99149550 | 0.99220403 | 0.99372285 |
| 09-17 | 0.98512717 | 0.98642613 | 0.98921842 |

| 路径 | 精确区间收益 | 精确最大回撤 | 页面四舍五入 | 一次性费用占起始资金 |
|---|---:|---:|---:|---:|
| A | -0.02789133 | -0.02789133 | -2.79% / -2.79% | 0 |
| B | -0.02551882 | -0.02551882 | -2.55% / -2.55% | 0.00004292 |
| C | -0.02006039 | -0.02006039 | -2.01% / -2.01% | 0.00012794 |

例如 A 的收益为 `0.97210867 - 1 = -0.02789133`，最大回撤为 `0.97210867 / 1 - 1 = -0.02789133`。这不是显示精度造成的巧合：底层数值也完全相同。当前组合与 A 相同，是因为 A 本身保持当前权重、换手为零。

反例使用归一化小样本 `[1, 1.1, 0.99, 1.05]`：区间收益 `1.05 - 1 = +5%`；最大回撤 `0.99 / 1.1 - 1 = -10%`。同一套现有函数能输出不同值，进一步排除“两列绑定同一公式”的怀疑。

要在 `chenchen` 目录复现当前三条路径，下面的只读命令会打印实际模拟结果：

```powershell
node -e "const t=require('./tools/financial-tools'); console.log(JSON.stringify(t.runSimulation().output.comparisons.map(p=>({id:p.plan_id,metrics:p.metrics,curve:p.curve})),null,2));"
```

## 两种处理方案及影响面

### 方案一：另设有代表性的演示数据窗口（建议后续评审后采用）

增加一个有中途高点、跌落和恢复的明确合成样例，让终点不再等于最大回撤低点。保留现在的样例用于回归；不要为了让数字不同而隐瞒或篡改结果。

影响：数据文件、日期和价格快照校验、相关性 / 集中度诊断中的历史指标、候选路径比较、费用后曲线、情景重采样、黄金测试与截图都会需要重新核验。若改最后价格，还会改变持仓总值 ¥31,080.00；可优先保持当前末端价格和资产数量，另建清楚命名的演示场景。此方案未在本轮执行。

### 方案二：修改公式（当前不建议）

在现有“净值起点为 1”的约定下，两套公式与费用处理正确，不应为了避免相同数字改公式。

若未来允许任意未归一化资产值，区间收益需改为 `V_last / V_first - 1`，并统一决定费用是在路径中扣除还是在指标中扣除；最大回撤仍是对截至当时的峰值计算最大跌幅。必须增加上升、下降、先升后跌、回升、非单位起点、费用与零值异常测试。影响所有投资指标、排序、结果摘要、证据和静态演示输出，需要另行授权与回归。此方案不属于本轮修复，也未执行。
